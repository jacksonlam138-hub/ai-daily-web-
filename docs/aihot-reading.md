# AI Daily：精选来源迁移与克制型阅读界面

## 当前发布决策：双源隔离，默认恢复原采集

2026-09-11 用户决定先恢复原采集方式，同时自行联系 AIHOT 团队确认授权。本节覆盖下文第一版本地方案的来源选择：

- `AI_DAILY_SOURCE=legacy`（默认，未知值也回退此模式）：使用原 `store.ts`，保留原有新闻采集与多角色分析流程。首页取原源最近一期；首页、日期页、往期和搜索都不会读取 AIHOT 缓存。
- `AI_DAILY_SOURCE=aihot`：显式选用 AIHOT 私有缓存。两种模式完全隔离，不把同日期两源混成一期。无缓存时显示空状态，不伪装成原源内容。
- 这是服务端配置，不是读者可通过 URL、按钮或本地存储切换的选项。公开生产环境先保持默认原源；AIHOT 授权和线上存储方案落实后再启用。
- 原采集任务未曾删除，无需重新创建定时任务。本轮不生成新一期新闻，不代发授权邮件，也不触发群消息。现有线上 9 月 9 日的 5 条原采集数据原样保留。
- `.vercelignore` 显式排除 `.local/`、本地截图与环境文件，避免 CLI 发布时上传私有 AIHOT 缓存。授权前，不将真实上游数据提交到公开仓库。
- 验证新增双源隔离测试：即使 AIHOT 缓存损坏，原源模式仍正常读取；同日期切换不混源；AIHOT 空缓存不偷偷回退原源。
- `pnpm daily:sync` 仍是显式的 AIHOT 本地同步命令，不会自动改变阅读模式；原采集继续走原有 skill / `store.ts` 流程。
- 发布使用现有 Vercel CLI 登录，并固定 pnpm 11.9.0，启用构建环境 `ENABLE_EXPERIMENTAL_COREPACK=1`。生产运行环境显式设置 `AI_DAILY_SOURCE=legacy`。

## 决策与范围

2026-09-11 用户确认：沿用原 AI Daily 的「新闻 + 多角色视角」核心，来源改为卡兹克的 AIHOT 日报；采用 Apple 启发的浅色方向、PingFang SC 优先、整卡打开原文，减少图标、按钮和冗余信息。当前用途是个人非商业工具。

本轮在原仓库实现首页、日报、往期和搜索；保留原 `store.ts` 历史数据，不迁移或重写既有条目。旧订阅、邮件、社交推送与后台配置不是新版阅读入口，本轮不启用、不发送，也不改变其旧数据管线。原有定时任务及线上部署未切换，避免把本地验证误当上线。

## 数据路径

AIHOT 日报索引 → 最新已发布日期 → 正式日报 → 边界解析 / 原文去重 → 私有本地快照 → 可选角色解读 → 原有 Next.js 阅读站。

- 官方契约：https://aihot.news/agent 、https://aihot.news/openapi-v1.json 。
- GET `/api/v1/dailies?limit=1`，再 GET `/api/v1/dailies/{date}`；匿名读取，无密钥。索引日期优先，不猜测当日路径，不拿 selected feed 冒充日报。
- 正式日报包含 `sections` 与 `flashes`，08:00 北京时间发布。显示真实覆盖窗口，不将生成时间编造为逐条新闻发布时间。
- 上游日报无逐条评分、ID、角色分析。应用只为内部身份生成稳定 ID，不虚构评分。去重保留原文锚点，仅忽略 utm 参数。
- 只规范化站点所需字段，不抓取完整原文，不声称逐条独立事实核验；原始作者、链接和 AIHOT 来源均保留。
- 快照保存在 `.local/aihot/YYYY-MM-DD.json`，Git 忽略、文件权限 0600，不放 `public/`。原子替换，重复同步不追加重复新闻。
- 使用 ETag / If-None-Match / 304。429/503 不自动密集重试，报告 Retry-After 并保留旧版；重试需遵守响应等待时间。显式日报 403/404 将该快照改名为 `.withdrawn`，不再被阅读器加载，可恢复。没有发布时不伪造新一期。
- 上游日报尚无历史撤稿增量接口。仅复核最新一期，不能宣称自动发现所有历史撤回；正式长期运行需补历史复核/失效方案。

## 角色解读

产品、设计、品牌、投资、入门；另有「只看新闻」。角色只影响分析，不筛掉新闻、不改上游顺序；偏好保存在浏览器本地。

`ReadingItem` 是现有新闻模型的阅读投影，保留旧角色键，增加 design。旧数据不伪装成 AIHOT 内容，不将历史推荐理由兜底给其他角色。原评分模型仍留给原有管线，新精选不使用它。

解读从本机已登录的 Claude CLI 生成，无工具、无 MCP、无技能执行，不保存会话；新闻被明确作为非可信输入。只使用标题和摘要，1–2 句，相关性不足允许整个条目或某个角色留空。UI 只显示非空解读，并标注「AI 解读」。这不是对模型输出真实性的形式化保证。

分析缓存绑定 `sourceHash + prompt version`；摘要、标题、链接变化时旧建议失效。校验条目完整性、角色键、长度，空对象代表主动克制，不会每天重新生成来凑数。模型故障不阻断新闻，命令以非零退出并保留最后有效状态。

## 本地运行

需要 Node.js 22.18+（本轮使用 25.8.1）、pnpm、已登录 Claude CLI；不新增依赖，不嵌入或复制 PingFang 字体文件。非 Apple 设备使用系统字体回退。

```sh
pnpm daily:sync
pnpm dev --hostname 127.0.0.1 --port 4327
```

重复同步沿用有效分析。确需重做分析：`pnpm daily:sync --refresh-insights`。此命令会产生模型用量，不发送邮件、群消息或推文。

本轮实际样本：2026-09-11，16 条；产品 11、设计 4、品牌 2、投资 9、入门 5 条解读，2 条完全不附建议。这是本次生成结果，不是固定配额。重复执行得到 `changed: false` 与 `insights: cached`。
